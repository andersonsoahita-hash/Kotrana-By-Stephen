# Kotrana by Stephen

Application personnelle de suivi de salle : séances A/B, charges, historique, santé, photos. *Voir clair. Tenir.*

- Une seule page : `index.html` (aucun serveur, aucune dépendance à installer).
- Les données restent sur ton appareil (stockage du navigateur). Pense à **Moi → Sauvegarde → Exporter** de temps en temps.
- Sur iPhone : ouvre l'adresse dans Safari, puis Partager → « Sur l'écran d'accueil ».
